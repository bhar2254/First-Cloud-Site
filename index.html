Cloudflare Pages Setup

Deploy with Cloudflare Pages + GitHub

Follow these steps to create a Cloudflare Pages application with automatic GitHub deployments.

1. Prepare Your GitHub Repository

  • Create or navigate to a GitHub repository that contains your static site code (HTML, JS, CSS, etc.).
  • Ensure your project is pushed to the main branch (or another branch of your choice).

2. Log in to Cloudflare

  • Go to pages.cloudflare.com.
  • Log in using your Cloudflare account, or create one if you don’t have it.

3. Create a New Pages Project

  • Click "Create a project".
  • Connect your GitHub account and authorize Cloudflare Pages to access your repositories.
  • Select the repository you want to deploy.

4. Configure Deployment Settings

  • Select the branch to deploy (e.g., main).
  • Set the build command (if using a static site generator like Hugo, Next.js, etc.).
  • Specify the output directory (e.g., dist, build, or public).

5. Deploy and Test

  • Click "Save and Deploy".
  • Wait for the deployment to complete. You’ll receive a live preview URL like your-project.pages.dev.
  • Every new push to the selected branch on GitHub will trigger an automatic deployment.
